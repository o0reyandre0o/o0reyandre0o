## Hola, soy Andre 👋

Hago páginas web y me encargo de que aparezcan en Google. Soy de Cabimas, Venezuela, y dirijo **[Prisma Develop](https://prismadevelop.com/)**, mi estudio de desarrollo web. También soy Lead Web Developer en **Toc Toc Marketing** y trabajo con **Polimedios**.

- 🛠️ Temas de WordPress a medida, landings y apps web pequeñas (menús, reservas, pedidos).

- 🤖 Programo con IA a diario, pero reviso cada cambio antes de publicarlo.
